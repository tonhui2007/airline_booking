# Airline Booking Analytics — Gói sinh viên

- `00_BAT_DAU_TAI_DAY.md`: hướng dẫn khởi động.
- `De_bai_Hang_khong.docx`: đề bài chính thức.
- `airline_student_starter.ipynb`: notebook khung, chưa có lời giải.
- `data/airline_bookings_dirty.csv`: dữ liệu bẩn 10.325 × 24.
- `data/data_dictionary.csv`: từ điển dữ liệu.
- `templates/`: khung báo cáo, insight, README và cleaning log.
- `tools/kiem_tra_nop_bai.py`: công cụ tự kiểm tra cấu trúc bài nộp.

Dữ liệu và tên hãng đều là mô phỏng phục vụ học tập. Không có đáp án số liệu trong gói sinh viên.
